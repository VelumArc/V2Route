Proxy V2Route

Open-source notices / 开源声明

Proxy V2Route is a local proxy-profile manager. It is not an official v2rayN product and does not provide proxy servers.

Proxy V2Route 是本地代理情景管理器，不是 v2rayN 官方产品，不提供代理服务器。

Privacy and data flow / 隐私与数据流向

Profile settings are saved in this browser. Imported node links and their credentials are sent to the Proxy V2Route companion on your computer, where they are stored and used to connect to your selected proxy. When you use a local v2rayN configuration, the companion reads its node information locally.

情景设置保存在当前浏览器中。导入的节点链接及其凭据会交给本机 Proxy V2Route 配套组件保存，用于连接你选择的代理。使用本地 v2rayN 配置时，组件会在本机读取其中的节点信息。

Browser requests follow your chosen route: through its proxy servers, or directly when a direct route applies, to the destination websites. Those proxy and website operators process the connection data they receive. The Proxy V2Route developer does not receive your node links, credentials or browsing requests. Proxy V2Route does not provide proxy servers.

浏览器请求按你选择的线路，通过相应代理服务器或直连方式到达目标网站；这些代理和网站的运营方会处理其接收到的连接数据。Proxy V2Route 开发者不接收你的节点链接、凭据或浏览请求，Proxy V2Route 也不提供代理服务器。

Manual proxy usernames and passwords are saved locally with the browser profile and included in profile exports. Authenticated HTTP(S)/SOCKS5 uses the local companion. Credentials never enter PAC scripts, public catalogs or diagnostic requests.

手动代理账号密码随情景保存在浏览器本地，并包含在情景导出中。带认证的 HTTP(S)/SOCKS5 通过本地组件连接，凭据不写入 PAC、不进入公开节点列表或检测请求。请妥善保管导出。

The complete Windows package includes Xray. Once the companion is installed, the explicit core install/repair action can retrieve a pinned official Xray release from GitHub, checks archive and executable SHA-256 hashes, and selects the verified core for the next route apply. Active connections keep running. A missing Windows companion still requires running the separate installer once.

Windows 完整包已包含 Xray。安装组件后，主动点击核心安装/修复可从 GitHub 获取固定官方版本，核验压缩包和程序的 SHA-256，供下次应用线路使用，当前连接保持运行。缺失 Windows 组件时仍需首次运行独立安装器。

IP Tools / IP 工具

Entering IP Tools or clicking Check again contacts ipify at api.ipify.org (IPv4) or api64.ipify.org (IPv4/IPv6). It receives your exit IP and ordinary HTTP/network details, including browser-supplied technical headers such as User-Agent and Origin when sent. Requests omit browser credentials and the referrer. Each request has a new random cache-busting value; Proxy V2Route does not proactively append account or device identifiers. Your profile/node names, links, credentials, browsing history and current check result are not sent to ipify or a developer server.

进入 IP 工具或点击重新检测时连接 ipify 的 IPv4 或 IPv4/IPv6 端点；对方收到出口 IP 和浏览器常规请求信息，包括自动附带的技术请求头（可能含 User-Agent、Origin）。请求不携带浏览器凭据或来源页；每次新的随机防缓存值V2Route 不主动附加账号或设备标识。不发送情景/节点名、链接、节点凭据、浏览历史或当前检测结果给 ipify 或开发者服务器。

Only the current successful result, its time and displayed profile label remain in IP Tools page memory. Leaving IP Tools, reloading or closing the page removes them. Results are not saved or exported with settings. IP Tools checks once on entry, with explicit retries but no periodic checks. Each ipify request is limited to 8 seconds and 4 KiB; the displayed duration is HTTP time, not ping or bandwidth. Copying is user-initiated; the diagnostic report excludes IP values, profile names and credentials.

仅保留当前成功结果、时间和情景名称于本页内存，离开、刷新或关闭即清除，不写入扩展存储或设置导出。IP 工具进入时检测一次，不周期检测；每次 ipify 请求最长 8 秒、响应最多 4 KiB，耗时是 HTTP 时间，不是 ping 或带宽。复制由用户主动触发，诊断报告不含 IP 值、情景名或凭据。

BrowserLeaks DNS/WebRTC links open only when clicked without adding the detected IP or profile. The Ping0 original-page link includes the detected IP. External pages run their own checks under their own policies.

BrowserLeaks DNS/WebRTC 外链仅点击后打开，不附加检测 IP 或情景；Ping0 原网页链接包含已检测 IP。外部页面自行检测并按自身政策处理数据。

Popup connection checks / 弹窗连接检测

Opening the toolbar popup, a successful profile switch, or hovering/focusing/clicking its status can send one bounded request to https://api64.ipify.org?format=json. Hover/focus checks are at least 15 seconds apart; clicking can retry and overlapping requests are coalesced. Each request has an 8-second deadline and a 4 KiB response limit. No periodic polling, automatic retry loop or all-node scan runs; the popup does not start Ping0, download or native tests.

打开工具栏弹窗、成功切换情景，或悬浮、聚焦、点击状态，可向 ipify 双栈端点发起一次有限请求。悬浮/聚焦至少间隔 15 秒，点击可重试，重叠请求合并；每次最长 8 秒、响应最多 4 KiB。不周期轮询、不循环重试、不扫描全部节点，也不会由弹窗启动 Ping0、下载或本机测试。

ipify receives the exit IP and ordinary network headers, possibly including User-Agent and an installation-specific extension Origin. Requests omit browser credentials and referrer and include a fresh random cache-buster. Profile/node names, proxy credentials and browser proxy configuration are not sent to ipify or the developer. The provider controls its own logging and retention; this is not an anonymous-request guarantee.

ipify 收到出口 IP 和常规网络请求头，可能包括 User-Agent 与安装相关的扩展 Origin；请求省略浏览器凭据、来源页，并添加新的随机防缓存值。不向 ipify 或开发者发送情景/节点名、代理凭据或浏览器代理配置。服务商自行决定日志和保留方式，不能据此保证请求匿名。

The extension locally compares actual browser proxy configuration/control state with the applied profile before and after checking. Green requires a valid response and matching settings; red reports an observed check/configuration failure, yellow means pending and gray means unconfirmed or at least 30 seconds old. The tooltip contains only Current connection status · Normal / Error / Checking / Unconfirmed. Failure does not prove the node offline; success verifies only this request, not every destination or chain hop. Rules/PAC/system settings and VPN/TUN can route other traffic differently.

扩展在本机核对检测前后的实际浏览器代理配置、控制状态与已应用情景。有效响应且配置吻合才为绿色；红色为本次检测/配置异常，黄色为检测中，灰色为未确认或已满 30 秒；提示仅显示当前连接状态 · 正常 / 异常 / 检测中 / 未确认。失败不等于节点确定离线，成功仅确认本次请求，不代表所有目标或链路每一跳；规则/PAC、系统设置和 VPN/TUN 可能使其他流量走不同路径。

Popup results, timestamps and reasons stay only in its memory. Closing it aborts/discards pending work and clears results; none are saved or exported. A changed profile invalidates old evidence.

弹窗结果、时间和原因仅在其内存，关闭即取消或丢弃待完成请求并清除结果，不保存、不导出；情景变化使旧结果失效。

Ping0 public report / Ping0 公开报告

On entry, existing Ping0 permission allows the detected IP report to load. Check again or Retry Ping0 report can request optional permission in your click gesture. The report uses https://ping0.cc/ip/{detected-IP}. Denial still allows IP detection and an original-report link. Firefox also requests optional location-data consent. Ping0 receives the queried IP, the connection exit IP and ordinary HTTP data. The report request omits cookies/credentials and referrer, rejects redirects and is limited to 8 seconds / 512 KiB. Proxy rules may route Ping0 differently from ipify.

进入页面时通过 ipify 检测出口，已有 Ping0 授权时自动读取公开报告；未授权时仅在点击“重新检测”或“重试 Ping0 报告”后申请可选权限。拒绝后仍可检测 IP 并打开原网页；Firefox 同时申请可选位置数据许可。Ping0 收到查询 IP、连接出口 IP 和常规 HTTP 信息；请求省略凭据、Cookie、来源页，不跟随重定向，最长 8 秒、最多 512 KiB。代理规则可能为两个服务选择不同线路。

The title and report reference must match the requested IP. Only actual report-row text is displayed: location, ASN/owner/organization, type, risk, native status and shared-user estimates when present. Remote scripts, ads, images, styles, frames and event handlers never enter the interface. Text retains the public page's language and source attribution; Proxy V2Route does not infer missing fields. Reports stay in page memory and clear with IP results. If the page returns a challenge, login, denial or missing result, the original page link is offered without bypassing protections. There is no paid API, API-key input or key storage.

网页标题与报告引用必须匹配查询 IP。只展示实际存在的结果文字：位置、ASN/所有者/企业、类型、风控、原生状态与共用人数估算。不加载远程脚本、广告、图片、样式、嵌入页或事件处理；保留网页原文和来源，不推断缺失字段。报告仅在页面内存，随 IP 结果清除。验证、登录、拒绝或缺失结果时提供原网页入口，不绕过保护；无付费 API、Key 输入或保存功能。

Manual network tests / 手动网络测试

Download testing sends one bounded HTTPS request to Cloudflare speed.cloudflare.com, at most 10 MiB response payload plus protocol overhead and 15 seconds. It follows browser proxy rules and displays sample throughput including setup time, not guaranteed broadband maximum. The provider sees ordinary IP/HTTP metadata; no configuration credentials are sent. Payload chunks are discarded, no upload occurs and no tests run automatically. Ping/TCPing call the local companion for bounded probes to the selected proxy server, a custom endpoint or a public preset through the computer's system network outside the browser proxy. System VPN/TUN may affect them; cancellation discards the UI result while the bounded native request may finish briefly afterward.

下载测试仅主动点击后向 Cloudflare speed.cloudflare.com 发送一次有限 HTTPS 请求，最多 10 MiB 数据加协议开销、最长 15 秒；遵循浏览器代理，显示包含建连的小样本吞吐量而非宽带峰值。对方收到常规 IP/HTTP 信息，不收到配置凭据。响应分块丢弃，无上传或自动测试。Ping/TCPing 调用本机组件，对当前代理服务器、自定义地址或公共预设有限探测，使用浏览器代理之外的系统网络，仍可能受系统 VPN/TUN 影响；取消后丢弃界面结果，有限本机请求可能稍后结束。
