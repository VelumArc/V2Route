# Website catalog / 网站连通列表

The 52-entry list is a maintained local selection of public service homepages. Category research used the V2Fly community domain lists, including the [AI category](https://github.com/v2fly/domain-list-community/blob/master/data/category-ai-!cn) and linked vendor lists, on 2026-11-14. Entries and labels are authored here; no upstream executable code is copied. The catalog is bundled so an unreviewed remote list cannot add targets during a test.

列表按 AI、开发工具、视频音乐、社交、国内服务、常用服务分组。本地打包固定 52 个入口，检测前可筛选、勾选。只请求公开图标地址、不携带登录凭据；不声称检测账号或地区解锁。
